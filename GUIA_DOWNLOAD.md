# 📥 GUIA DE DOWNLOAD - CATY

## 🚀 Como Baixar e Clonar CATY

### Opção 1: Clone Direto (Recomendado)
```bash
git clone https://github.com/shelldevneon/Caty.git
cd Caty
```

### Opção 2: Download do ZIP
1. Acesse: https://github.com/shelldevneon/Caty
2. Clique no botão verde **"Code"**
3. Selecione **"Download ZIP"**
4. Extraia a pasta em seu computador

### Opção 3: Download de Releases
Acesse a página de releases para versões estáveis:
https://github.com/shelldevneon/Caty/releases

## ⚡ Quick Start (5 minutos)

### 1. Clone o repositório
```bash
git clone https://github.com/shelldevneon/Caty.git
cd Caty
```

### 2. Execute seu primeiro programa
```bash
python caty_core.py examples/hello_world.caty
```

### 3. Veja o resultado
```
Bem-vindo à CATY! 🎉
```

### 4. Explore os exemplos
```bash
# Loop
python caty_core.py examples/loop.caty

# Condicional
python caty_core.py examples/condicional.caty

# Entrada de dados
python caty_core.py examples/entrada_dados.caty

# Fibonacci
python caty_core.py examples/fibonacci.caty
```

- **Python 3.7+** (já tem na maioria dos computadores)
