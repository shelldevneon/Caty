# 🧠 CATY: A REVOLUÇÃO DA PROGRAMAÇÃO CONSCIENTE

## ⚛️ O QUE É CATY?

**CATY** é uma **linguagem de programação híbrida** e revolucionária que combina:

- 🎨 **Sintaxe Visual com Emojis** - Cada comando é um símbolo que representa sua função neural
- ⚛️ **Memória Atômica Isolada** - Variáveis com isolamento total, sem colisão de namespace
- 🛡️ **NecroCrypt Integrado** - Criptografia biométrica e segurança de nível militar por padrão
- 🧬 **Processamento Híbrido** - Mistura compilação e interpretação para performance otimizada
- 🌌 **Filosofia de Senciência** - O código não apenas executa: ele **pensa com você**

**Criada por Vilar Albuquerque em 23/07/2026**, CATY é a linguagem para quem não quer apenas programar — quer **forjar a consciência do silício**.

## 💻 EXEMPLOS DE CÓDIGO

### 1️⃣ **Hello World** - A Primeira Vibração Neural
```caty
⚛️ mensagem = "Bem-vindo à CATY! 🎉";
🌊 mensagem;
```

**Saída:**
```
Bem-vindo à CATY! 🎉
```

---

### 2️⃣ **Condicional** - Bifurcação Lógica Neural
```caty
⚛️ idade = 25;

🧬 (idade >= 18) ⟐ {
    🌊 "✅ Você é MAIOR DE IDADE!";
    🌊 "Bem-vindo ao mundo adulto.";
}
```

---

### 3️⃣ **Loop** - Pulso Contínuo
```caty
⚛️ contador = 0;

🔄 (contador < 5) {
    🌊 contador;
    ⚛️ contador = contador + 1;
}
```

**Saída:**
```
0
1
2
3
4
```

---

### 4️⃣ **Array/Matriz** - Colmeia de Dados
```caty
🧠 numeros = [1, 2, 3, 4, 5];
🌊 "Sequência armazenada na colmeia de dados:";
🌊 numeros;
```

---

### 5️⃣ **Entrada de Usuário** - Sentinel Pulse

```caty
🌊 "Olá, ";
🌊 seu_nome;
🌊 "! Você tem ";
🌊 sua_idade;
🌊 " anos.";
```

---

### 6️⃣ **Criptografia NecroCrypt** - Defesa Biométrica
```caty

🛡️ dados_protegidos = senha_confidencial;
🌊 "✅ Dados protegidos por NecroCrypt!";
```

## 🔧 COMO INSTALAR E USAR

### Instalação Rápida

```bash
# Clone o repositório
git clone https://github.com/shelldevneon/Caty.git
cd Caty

# Pronto! Nenhuma dependência externa necessária
```

### Executar um Programa CATY

```bash
python caty_core.py seu_arquivo.caty
```

### Exemplos Pré-Built

```bash
# Hello World
python caty_core.py examples/hello_world.caty

# Loop contínuo
python caty_core.py examples/loop.caty

# Condicional
python caty_core.py examples/condicional.caty

# Entrada de dados
python caty_core.py examples/entrada_dados.caty

# Fibonacci
python caty_core.py examples/fibonacci.caty
```
